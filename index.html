U+9571 · 镱 · one character, two questions一个字，两个问题一つの字、二つの問い

Read it as type.把它当作字来读。文字として読む。

Its left half, 钅, is the simplified form of the metal radical. Japanese fonts write that radical as 金, so a Japanese font has never drawn 钅. Extending a font to characters built from parts it has never drawn is the problem behind my font study. In the study I create the gap on purpose: I remove one component family from a font's training glyphs and measure what that costs.

左半边的 钅 是简体的金字旁。日文字体把这个偏旁写作“金”，所以一款日文字体从没画过 钅。把字体扩展到由它没画过的部件组成的字，就是我的字体研究要解决的问题。实验里，我有意制造这种缺口：从字体的训练字形中删去一类部件，再测量这样做的代价。

左半分の 钅 は、金偏の簡体字です。日本語のフォントはこの偏を「金」と書くので、日本語フォントが 钅 を描いたことは一度もありません。フォントを、まだ描いたことのない部品でできた字にまで広げること。それが私のフォント研究の課題です。実験ではこの欠落をあえて作り、ある部品類を学習字形から取り除いたときの代価を測ります。

Component support gaps in CJK font generation中日韩字体生成中的未见部件问题中日韓フォント生成における未見部品の問題

When a CJK font is extended beyond the few thousand characters it ships with, some new characters contain a the font never drew. I measure what that costs. Each target font is fine-tuned twice: once with every training glyph that contains a given component family removed, and once with the family kept. I then compare the generator's error on the same held-out characters. The design covers (小, 日, 竹, 米), each with 3 random seeds. It is crossed with a generator pretrained on 330 other fonts, with or without that family in the pool. A placebo control instead removes random unrelated characters from the pretraining pool. A replication on a second, architecturally different generator is under way.

把一款中日韩字体扩展到原有的几千字之外时，有些新字会包含字体从未画过的。我测量这件事的代价。每款目标字体微调两次：一次删去训练字形中含某类部件的全部字，一次保留，然后在同一批留出字上比较生成器的误差。实验覆盖（小、日、竹、米），每格 3 个随机种子；另与预训练条件交叉：生成器先在 330 款其他字体上预训练，预训练池含或不含这类部件。另设随机删除对照（即安慰剂对照）：从预训练池里随机删去与该部件无关的字。在另一种架构的生成器上的复现正在进行。

中日韓フォントを元の数千字の外へ広げようとすると、新しい字の一部には、そのフォントが一度も描いたことのないが含まれます。私はその代価を測っています。対象フォントごとに微調整を 2 回行います。一度はある部品類を含む学習字形をすべて除き、もう一度は残したまま。そのうえで、同じ留保文字に対する生成器の誤差を比べます。実験は（小・日・竹・米）で、各セルに乱数シードを 3 つ使います。さらに事前学習の条件と交差させます。生成器はまず他の 330 フォントで事前学習し、その事前学習プールにこの部品類を含めるかどうかを変えます。ランダム削除対照（いわゆるプラセボ対照）として、部品と無関係な字をプールからランダムに除く条件も設けています。別のアーキテクチャの生成器での再現実験を進めています。

Pseudopotential conventions in foundation interatomic potentials通用机器学习势如何继承赝势约定汎用機械学習ポテンシャルは擬ポテンシャルの慣習をどう受け継ぐか

Foundation interatomic potentials are trained on DFT labels, and the choices behind those labels are not fixed. In 2023 the Materials Project changed the pseudopotential it uses for from Yb_2 to Yb_3. Models of the same architecture (MACE, eqV2, Nequix) have been released twice: once trained on MPtrj, built before the change, and once on OMat24, which uses Yb_3. This gives a natural experiment. I ask whether the models inherit the convention of their labels, where in the network it is carried, and whether retraining only a small, ytterbium-specific set of weights can move a model from one convention to the other without changing its other elements.

通用机器学习原子间势（基础模型）用 DFT 计算的标签训练，而这些标签背后的计算设置并非一成不变。2023 年，Materials Project 把的赝势从 Yb_2 换成了 Yb_3。同一种架构（MACE、eqV2、Nequix）的模型都有两个公开版本：一个用更换之前构建的 MPtrj 训练，一个用采用 Yb_3 的 OMat24 训练。这构成了一个自然实验。我研究这些模型是否继承了训练标签的约定，约定由网络的哪一部分承载，以及只重训一小组镱专属的权重，能否把模型从一种约定移到另一种，而不改变其他元素的结果。

汎用機械学習原子間ポテンシャル（基盤モデル）は DFT 計算によるラベルで学習しますが、そのラベルを支える計算設定は不変ではありません。2023年、Materials Project はの擬ポテンシャルを Yb_2 から Yb_3 に替えました。同じアーキテクチャ（MACE、eqV2、Nequix）のモデルにはそれぞれ公開版が二つあり、一つは変更前に構築された MPtrj で、もう一つは Yb_3 を採用した OMat24 で学習されています。これが自然実験になります。私は、これらのモデルが学習ラベルの慣習を受け継いでいるか、その慣習をネットワークのどの部分が担っているか、そしてイッテルビウム固有の少数の重みだけを再学習すれば、他の元素の結果を変えずにモデルを一方の慣習から他方へ移せるかを調べています。
