# Fonts used on beichen.li

- **Geist / Geist Mono** (Vercel), SIL Open Font License 1.1 — `Geist-OFL.txt`. Latin subsets of the variable fonts.
- **OPPO Sans 4.0** (OPPO), free for commercial use under OPPO's own terms. Subset to the characters used on this site; not offered for download or redistribution.
- **LXGW WenKai** (霞鹜文楷), SIL Open Font License 1.1 — `LXGW-WenKai-OFL.txt`. Subset to the four characters of its name.
- **Murecho** (The Murecho Project Authors), SIL Open Font License 1.1 — `Murecho-OFL.txt`. Japanese text; subset to the characters on the Japanese version of this site.
- **M PLUS 2** (The M+ FONTS Project Authors), SIL Open Font License 1.1 — `MPLUS2-OFL.txt`. One glyph (蘭) that Murecho does not include.
